# البكور — حاضنة الودجات (القائمة الجانبية) · مستند التصميم

> **الحالة:** مسودة للمراجعة — لا كود بعد. **التاريخ:** ٨ نوفمبر ٢٠٢٦.
> **الوسوم:** 🟢 قرار المالك · 💡 اقتراح (ينتظر الموافقة) · ❓ سؤال مفتوح · ⚠️ خطر.

---

## ١. الهدف في سطرين
قائمة جانبية في كروم تجمع أدواتنا **كودجات** تُرتَّب وتُنقل بسهولة، تبدأ بساعة البكور وتتسع لأدوات جديدة مع الوقت، وتصير لاحقاً منصة بحسابات مستخدمين.

## ٢. القرارات المتخذة
- 🟢 **البداية بالساعة** — أول ودجة تُبنى.
- 🟢 **قائمة جانبية** بودجات سهلة **إعادة الترتيب وتغيير المواضع**.
- 🟢 **نطوّرها مع الوقت**، وكل تحديث يظهر أولاً بأول؛ و**حسابات مستخدمين مستقبلاً**.
- 🟢 **القائمة صفحة ويب مستقلة تُستدعى** داخل الإضافة (لا كود مدمج فيها).
- 🟢 **المستودع: BUKUR.**
- (ملاحظة) يوجد مشروع Firebase باسم **BUKUR** (`bukur8`، خطة Spark المجانية، بلا تطبيقات بعد) — من لقطة شاشة المالك.

## ٣. البنية: «غلاف رفيع + تطبيق ويب» 💡

```
┌──────────── كروم ────────────┐
│ صفحة أي موقع │ القائمة الجانبية │
│              │ ┌──────────────┐ │
│              │ │ غلاف الإضافة  │ │  ← extension/ : صغير، نادراً ما يتغيّر
│              │ │ ┌──────────┐ │ │
│              │ │ │ تطبيق    │ │ │  ← app/ : مستضاف (Firebase Hosting)
│              │ │ │ الودجات  │ │ │     يتحدّث فوراً عند كل رفع
│              │ │ └──────────┘ │ │
│              │ └──────────────┘ │
└──────────────────────────────┘
نفس app/ يعمل أيضاً: في تبويب كامل («التوسيع») · وعلى الجوال كتطبيق ويب (PWA)
```

- **`app/`** — كل شيء: الحاضنة، الودجات، الإعدادات، والحسابات لاحقاً.
- **`extension/`** — إضافة Manifest V3 تفتح القائمة الجانبية وتعرض `app/` داخل إطار (iframe)، وزر «افتح في تبويب كامل».
- **لماذا:** التحديث المستمر بلا إعادة تثبيت، والحسابات مكانها الويب، وصفحة واحدة لكل الأجهزة. وكروم يمنع تشغيل كود مجلوب من الإنترنت **داخل** الإضافة، لكنه يسمح بعرض موقع داخل إطار (ثقة ~٨٠٪).

## ٤. عقد الودجة 💡
كل ودجة مجلد مستقل في `app/widgets/<id>/` بالشكل نفسه — إضافة أداة جديدة = إضافة مجلد، دون تعديل الحاضنة.

```js
// app/widgets/bukur-clock/index.js
export default {
  id: 'bukur-clock',            // ثابت للأبد — مفتاح التخزين
  name: 'ساعة البكور',
  icon: './icon.svg',
  sizes: ['s', 'm', 'l'],      // الأحجام المسموحة
  defaultSize: 'm',
  mount(el, ctx) {             // يرسم الودجة داخل el
    // ctx.store   → مخزن خاص بهذه الودجة فقط: get/set/subscribe
    // ctx.size    → الحجم الحالي، ويتغيّر بـ ctx.onResize
    // ctx.bridge  → قدرات المتصفح عبر الغلاف (لاحقاً؛ قد يكون غير متاح)
    return () => { /* تنظيف عند الإزالة */ };
  },
  settings: { /* اختياري: إعدادات تُعرض في قائمة الودجة */ },
};
```

**قواعد العقد:**
- الودجة **لا تلمس** DOM خارج `el`، ولا تخزين غيرها، ولا متغيرات عامة.
- الودجة **تعمل في أي عرض**: عمود القائمة الضيق، أو شبكة التبويب الكامل.
- منطق الحساب (الوقت، اليقظة…) في **دوال نقية منفصلة** تُختبر دون متصفح.

## ٥. الحاضنة (صفحة الودجات) 💡
| | القائمة الجانبية (ضيّقة) | التبويب الكامل («التوسيع») |
|---|---|---|
| الترتيب | عمود واحد، سحب لأعلى/أسفل | شبكة، سحب إلى أي خانة |
| لكل ودجة | طي/فتح · تغيير الحجم · إعدادات · إخفاء | نفسها |
| «أدواتي» | قائمة لإظهار وإخفاء الودجات | نفسها |

- **الحفظ:** الترتيب وحالة كل ودجة محلياً الآن (`localStorage`)، وعبر الحساب لاحقاً — الواجهة نفسها `ctx.store` فلا تتغيّر الودجات.
- **تصدير/استيراد** الإعدادات كملف JSON.
- **العربية أولاً واتجاه RTL**، وهوية Mind8x: أخضر داكن، برتقالي للإبراز، بيج للأرضية.
- **بلا إطار ولا خطوة بناء** (JavaScript عادي بوحدات ES) — نفس فلسفة إرث: سريع، رخيص، لا يتكسّر بالترقيات.
- ⚠️ عرض القائمة الجانبية يغيّره المستخدم بسحب حافتها، والإضافة لا تضبطه برمجياً (ثقة ~٨٠٪)؛ لذا «التوسيع» = تبويب كامل.

## ٦. الودجة الأولى: ساعة البكور 💡
**المصدر:** `index.html` الحالي (ساعة «AL DHAFAR 3»).

**ما يُنقل كما هو (الشكل والحسابات):**
- قرص ٢٤ ساعة بعقارب الساعات والدقائق والثواني والتاريخ.
- الإطار الدوّار يُسحب لتحديد وقت الاستيقاظ · زر «استيقظت الآن» · «تصفير» · وقت استيقاظ يومي بالساعة والدقيقة.
- ساعات اليقظة والحالة (نشيط · فعّال · متعب · نَم!) وشريط تقدّم اليقظة.
- أوضاع القرص: أبيض / ليل-نهار (١٨–٠٦ أو ١٩–٠٥)، وتدرّج الليل ثابت/متتبّع، ووضع الإطار يقظة/ليل-نهار.

**ما يتغيّر:**
- إعادة كتابة بلا React وBabel وTailwind من الإنترنت → JavaScript عادي وSVG. (السبب: الإضافات تمنع الكود المجلوب، وBabel في المتصفح بطيء ويتطلب `eval`.)
- الحسابات تخرج إلى `app/widgets/bukur-clock/time.js` (دوال نقية) ولها اختبارات.
- الإعدادات عبر `ctx.store` بدل مفتاح `aldhafar3` مباشرة — مع **ترحيل تلقائي** من المفتاح القديم حتى لا يضيع إعداد أحد.
- الأحجام: صغير (القرص فقط) · متوسط (القرص + الأزرار) · كبير (مع الإعدادات).
- **`index.html` الحالي يبقى يعمل** حتى تُثبت الودجة الجديدة أنها مطابقة.

**ملاحظة من قراءة الكود:** ساعات اليقظة تُحسب بباقي القسمة على ٢٤، فبعد ٢٤ ساعة يقظة تعود للصفر. نُبقيها كما هي الآن، ونسأل المالك ❓.

## ٧. الغلاف (الإضافة) 💡
- Manifest V3، صلاحية `sidePanel` فقط في البداية — أقل صلاحيات ممكنة.
- صفحة القائمة = إطار يعرض رابط `app/` المستضاف + زر «افتح في تبويب».
- تُثبَّت من «وضع المطوّر» أولاً، والمتجر لاحقاً إن أردنا.
- **الجسر (لاحقاً):** رسائل `postMessage` بين `app/` والغلاف لقدرات المتصفح (تجميع التبويبات، الكتم، التنبيهات) — مع قائمة بيضاء للنطاق المصدر. لا تحتاجه الساعة.

## ٨. الاستضافة والحسابات 💡
- **الاستضافة:** Firebase Hosting في مشروع `bukur8` (متاح في الخطة المجانية) — أو أي استضافة ثابتة. ❓
- **الحسابات لاحقاً:** Firebase Authentication هو المرشّح الطبيعي في نفس المشروع.
- ⚠️ **خطر يجب اختباره مبكراً:** داخل إطار في إضافة، يعامل كروم الموقع كطرف ثالث فقد يحجب أو يعزل التخزين والكوكيز، فيتعطّل تسجيل الدخول (ثقة متوسطة). **تجربة صغيرة** (المرحلة ٤) قبل بناء أي شيء على الحسابات. البدائل المعروفة: الدخول في تبويب كامل وتمرير الرمز عبر الغلاف.
- 🔒 **المستودع عام:** لا أسرار فيه أبداً. إعدادات Firebase للويب ليست أسراراً، لكن أي مفتاح خادم أو كود خادم للحسابات يكون في مستودع خاص.

## ١١. الاختبار والتحقق
- الدوال النقية: `node --test` (بلا اعتماديات).
- البصري: لقطات Playwright لكل حجم ودجة، بالعربية واتجاه RTL، وعرض قائمة جانبية.
- لا يُقال «يعمل» قبل تشغيله فعلاً في كروم.

## ١٢. أسئلة مفتوحة للمالك ❓
1. **الاستضافة:** Firebase Hosting في `bukur8`؟ وما النطاق (رابط Firebase الافتراضي أولاً، أم نطاق Mind8x)؟
2. **لغة الساعة:** الأزرار الحالية بالإنجليزية («Woke Up»، «Reset»). نعرّبها؟ والنص «AL DHAFAR 3» على القرص يبقى؟
3. **أكثر من ٢٤ ساعة يقظة:** تعود للصفر (الحالي) أم تُعرض كما هي؟
4. **أين الساعة منشورة الآن؟** (في شريط الإشارات المرجعية رابط «AL DHAFAR 3») — لنعرف إن كان أحد يستعملها فنحافظ على رابطها.
